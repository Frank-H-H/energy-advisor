# Contributing

Thank you for your interest in contributing to energy-advisor.

Please follow the documentation-driven workflow in docs/ and write tests for any new behavior.

1. Fork
2. Create a descriptive branch
3. Add/modify docs in docs/specifications when changing domain behavior
4. Add tests (unit and scenario/regression) before implementing behavior
5. Run tests and linters
6. Open a PR with a clear description and linked ADRs if applicable

Be conservative with design changes; prefer small, test-covered iterations.
